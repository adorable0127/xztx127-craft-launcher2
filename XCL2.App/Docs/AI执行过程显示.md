# AI 助手执行过程显示

在 AI 助手右上角打开设置，在“执行过程显示”中分别控制以下内容，保存后生效。

| 设置 | 默认 | 展示内容 |
| --- | --- | --- |
| AI 调用的子智能体 | 开启 | 实际调用的子任务、模型及执行状态 |
| 修改的代码 | 开启 | 成功写入文件后的修改前/修改后内容 |
| 正在修改的文件 | 开启 | 文件路径及等待确认、执行中、完成、失败或拒绝状态 |
| 执行的命令 | 开启 | 实际请求的命令、执行状态及结果 |
| 思考过程摘要 | 开启 | 模型接口明确返回的摘要字段 |
| 思考过程 | 开启 | 模型接口明确返回的可显示推理文本 |

显示开关与文件、命令执行权限相互独立，也不会自动开启“深度思考”。没有实际子任务或工具操作时，不会生成虚构记录。接口未提供推理内容时，不会从普通回答中推测或补写；加密推理字段不作为可读文本展示。当前聊天接口默认采用 SSE 流式返回，第一段正文收到后立即显示。思考过程为独立的默认折叠项，子智能体和工具位于执行过程项中。接口若返回普通 JSON，则在该响应结束后显示。

子任务使用当前已配置的模型与接口，以独立请求完成分析；每轮默认最多两个（可在高级 API 设置中调整为 0–4 个），不再递归调用子任务，也不直接执行文件或命令。子任务的建议交回主助手，由主助手沿用现有操作权限完成后续工作。显示子智能体的开关本身不会触发额外调用。

操作记录随本地聊天历史保存，显示开关同样作用于历史记录。记录不会自动作为下一轮模型上下文重复发送。代码及命令输出采用有上限的显示文本；拒绝、失败和取消会与成功状态区分，未执行的代码不会标为已修改。

## Windows 验收

1. 使用没有新增字段的旧配置打开 AI 设置，检查六项显示默认勾选（已明确保存的旧设置仍保留）；分别保存、重启、恢复默认、导出再导入，检查所有开关。
2. 在已授权的测试工作目录中让助手修改小型文本文件：确认前显示等待状态，执行中显示路径，成功后展示修改前后内容。拒绝确认后应显示拒绝，不产生成功的代码改动记录。
3. 在“允许 AI 请求运行 Shell 命令”开启的环境中测试短命令、非零退出命令、超时和停止按钮，核对命令、结果和状态；仅开启“显示执行的命令”不应绕过原有权限。
4. 让助手将一个独立分析任务交给子智能体，核对真实任务、模型和结果；普通直接回答不应显示虚构子智能体。
5. 使用返回推理摘要/文本的接口，分别打开后两项，确认只展示相应字段；使用不返回推理字段的接口，普通回答仍应正常显示。
6. 请求中收起并重新打开面板，完成后切换历史、编辑消息创建分支、重新生成；操作记录不能混入其它会话，重复的进度更新不能生成重复卡片。
7. 检查只包含普通消息的旧聊天记录仍可打开。关闭某项显示后，其历史卡片应隐藏，重新开启可再次查看。

## 离线回归检查

源码根目录附有独立 .NET 8 检查项目，直接链接正式配置模型、响应解析器和子任务协议。覆盖旧配置默认值、六项开关独立保存、旧消息兼容、推理与正文分离、加密字段忽略、长文本截断、无效子任务拒绝及活动快照。它不访问接口、不需要密钥，也不执行文件修改或系统命令：

```powershell
dotnet run --project .\Tests\AiActivityRegression\AiActivityRegression.csproj
dotnet build .\XCL2.App.csproj -c Release
```

当前交付环境不能启动 .NET 运行时，也没有 Windows 桌面；以上命令及实机验收尚未执行，不能将静态结构检查视为实际编译或接口联调结果。新增回归项目及完整构建入口见源码根目录 README_本次更新.md。
