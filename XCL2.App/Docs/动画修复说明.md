# 动画与资源优化说明

## 默认状态与速度

默认启用动画，播放速度为 75%，每类强度为 100%，“完全没有动画模式”默认关闭。速度和强度是独立设置：速度改变时长，强度改变位移和淡入幅度，强度 0% 等同关闭。旧配置没有新增字段时采用这些默认值，已有明确关闭的动画偏好继续保留。

本次恢复可见的界面过渡：页面从透明淡入，并有 18 像素归位；默认 75% 速度下参考时长 320 毫秒，100% 时为 240 毫秒。窗口打开、恢复、最大化/全屏、弹窗、侧边栏和通知也恢复清晰可见的动效。保留同步设置起点、单次窗口过渡和及时清理时钟的修复，减少动画叠加和延后一帧重播。

点击反馈仍仅使用浅描边，避免点击文字时整体缩放或明显闪烁。3D 攻击最大 24°；受击手臂最大 8°、头部最大 4°、身体最大 3°。日常与攻击动作跟随总速度；受击事件沿用真实时间，红色只叠加于模型材质，最高 10% 浅红，闪光设定 80 毫秒，不受慢速设置拉长。

## 页面加载与二级导航的后续修复

本轮确认的阻塞来自加载流程：占位与目标页重复播放动画、目标页尚未完成首布局就开始计时，以及版本/模组/服务端扫描占用 UI 线程。`DispatcherPriority.Background` 仍在 UI 线程，不能替代真正后台的数据读取。

主导航现在先单独显示“正在加载”，让布局与一次合成提交完成后再构造页面。页面先设置入场起点，完成首次布局后才启动一段淡入和位移；加载层不参与页面入场动画。快速切页会取消旧请求并复位旧时钟，旧结果不会再覆盖当前页面；首页、基岩版与插件导航也接入同一流程。导航回调在实际加载和入场收尾后执行。

二级面板不再使用两层 Loaded 排队；同一次可见周期只播放一次。父页面入场时抑制子面板的初次动画，后续切分类、标签及详情时分别播放，避免透明度相乘或先完整显示再跳回起点。

- 版本选择、模组管理及快速开始向导：版本 JSON、目录与 JAR 扫描改为可取消后台任务，批量更新列表；安装或重命名后的选择仍核对原目录。
- 服务端实例：地址解析、端口与图标读取移到后台，冻结可跨线程使用的图像；UI 分批创建卡片。切页、隐藏时取消，返回可见时恢复当前列表加载。
- 设置页：首次展开字体列表时才后台获取一份名称快照；Java 探测与配置备份磁盘操作移到后台。
- 列表模板：连接 CanContentScroll，开启回收虚拟化和像素滚动；只有可见列表行需要生成控件。

加载图标为蓝紫色轨道，资源在 `Resources/Loading/orbit-loading.gif`（透明 128×128、60 帧、1.2 秒循环），并附生成脚本。应用使用同设计的原生 WPF 矢量与旋转时钟，以避免每帧 GIF 解码和 UI 定时器；主页面、版本/模组列表、服务端、资源详情与向导共用该设计。关闭加载动画或完全无动画模式时仍显示静态图标和“正在加载”。

渲染等待有取消、隐藏、卸载、关闭与超时收尾；未用固定长延时掩盖加载，也未将 WPF 控件构造放进工作线程。当前环境无法测量真实帧率，以上为实现与静态复核结果，不能据此承诺所有机器达到固定帧率。

## 强度滑杆的后续修复

本轮复核了滑杆事件、即时预览、保存及实际播放的整条调用链。页面和窗口过渡原本已读取强度；补齐了此前只检查开关的通知退场、通知拖动回弹，以及彩蛋窗口/按钮/磁贴位移的幅度计算。100% 保持原效果，低强度按比例减小淡入淡出差值、位移或回位距离；0% 直接完成操作，不残留透明或错位控件。

即时预览与保存相同值不再重复广播设置变化，避免自动保存强行截断刚开始的动画。修改某一分类时，只收尾参数确实改变的界面过渡；其它分类继续播放。

设置页为常用窗口、页面、弹窗和侧栏动画增加行内“预览”，滑杆停止变化后防抖播放一次，并复用实际 `UiAnimationHelper` 接口。按钮点击反馈与通知通过点击预览按钮触发；不会因拖动滑杆反复产生通知。强度控制幅度，总速度仍独立控制时长；手动保存、自动保存及撤销的原有语义不变。预览卸载后停止计时并清理动画。

## 完全没有动画模式

设置内新增“完全没有动画模式”，默认关闭。用户开启时显示：

> 这会降低 CPU 以及内存的占用，但是可能会变得有视觉污染

开启后展开资源优化选择，并立即暂停界面动画、纸娃娃动作和动态背景，不覆盖原速度、分类开关及强度偏好。关闭模式后恢复这些偏好。设置沿用即时预览、保存、自动保存、撤销和恢复默认流程。

| 选项 | 页面缓存 | 静态背景缓存 | 动态背景 |
| --- | --- | --- | --- |
| 内存优先 | 不保留额外页面 | 不保留额外位图缓存 | GIF 保留独立单帧、释放其余帧；视频关闭解码资源，显示静态底色 |
| CPU 优先 | 保留最多 2 个安全页面减少切换重建 | 保留完整比例位图缓存，复用背景绘制 | 停止 GIF 定时器、暂停视频，保留资源便于恢复 |
| 全能模式（默认） | 保留最多 1 个页面，按最近使用淘汰 | 保留 75% 比例位图缓存 | 暂停播放并保留恢复资源 |

页面复用仅限“更多”和“鸣谢与帮助”中经检查可复用的简单页面；设置、登录、下载、实例管理、AI、首页及有定时器或订阅生命周期的页面不纳入缓存。缓存随模式、策略和语言变化更新，窗口关闭时释放；不在切页时强制全局垃圾回收。模式关闭时，内存优先释放过的媒体按保留路径重新加载，其它策略恢复播放。资源取舍随页面与背景大小而变化，本次未测得固定的 CPU 或内存下降百分比。

快速导航时会在构造页面前检查请求是否仍有效，并取消过时的排队请求，避免创建不会显示却持有计时器或事件订阅的页面。

## 保留的修复

- 各类动画开关与强度仍可分别设置。已有 `--no-animation` 参数临时关闭本次进程动效，不改写保存的偏好；低性能模式继续暂停界面动画。
- 主窗口应用单次过渡，停用额外 DWM 尺寸过渡；普通最大化使用工作区，全屏使用完整显示器边界。
- 整窗透明用原生 layered alpha，勾选和滑块即时预览。恢复、显示、激活、DPI 或样式改变时检查实际状态。透明度低于 100% 时暂停云母/亚克力背景，关闭或恢复 100% 后恢复原选择。
- 移除两套增减窗口尺寸的强制刷新。含文字树不做按钮缩放和回弹，通知、滚动和弹窗清理旧时钟及计时器。
- 愚人节彩蛋的窗口移动、按钮躲避和磁贴位移同样遵守动画开关；未激活、隐藏、最小化或离开首页时停止相关定时器，卸载与关闭时清理外部订阅。
- 3D 模型卸载、隐藏、关闭和最小化时停止渲染。插件接口没有幅度/滤镜控制参数，攻击、受击、低强度及停用动画时使用内置模型；普通默认强度可恢复插件。
- 保留 `AiModelListFetcher.cs` 的显式 `using System.Net.Http;`，修复此前反馈的 CS0246；未改变请求逻辑。
